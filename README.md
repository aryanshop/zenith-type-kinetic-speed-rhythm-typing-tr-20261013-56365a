# Zenith Type: Kinetic Speed & Rhythm Typing Trainer

Zenith Type is a polished, high-performance web application designed to turn typing practice into a rhythmic, flow-inducing audio-visual experience.

## Features
- **Kinetic Audio Engine**: Powered by the Web Audio API, featuring harmonic synthesizer notes on correct keystrokes, bass pulses, and subtle error alerts.
- **Real-time Flow Visualizer**: HTML5 Canvas rendering particle bursts, expanding energy waves, and responsive visual feedback synced to your typing cadence.
- **Multiple Practice Modes**: Choose between Zen Flow, Speed Sprint, and Beat Sync environments.
- **Responsive & Accessible**: Fully accessible keyboard input management with clean CSS grid layouts and high-contrast typography.

## Local Run Instructions
1. Download or clone this repository.
2. Open `index.html` directly in any modern web browser.
3. Click inside the typing arena and begin typing.

## Technology Stack
- Pure Vanilla HTML5, CSS3, and JavaScript (ES6+).
- Web Audio API (Synthesizer & Rhythm Generator).
- HTML5 Canvas 2D Rendering.
- Zero external libraries, trackers, fonts, or network dependencies. Completely self-contained and static.
